# «Чё? Шашлык» — сайт (вариант 2)

Статический сайт без сборки: открыть `index.html` или выложить папку на любой хостинг.

- `assets/js/config.js` — телефон, адрес, часы, ссылки на WhatsApp / Telegram / MAX, карты, реквизиты (взято с cheshashlik.ru).
- `assets/js/menu-data.js` — все блюда и цены (меню и бар, сентябрь 2026).
- `assets/img/hero/` — фото для слайдера на первом экране, `assets/img/menu/` — фото блюд.
- `assets/brand/` — логотип, орнамент, фавикон из брендбука.

Заказ и бронь — звонком или сообщением в мессенджер, онлайн-оплаты нет.
