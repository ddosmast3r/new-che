# «Чё? Шашлык» — сайт (заменяет cheshashlik.ru)

Статический сайт: готовые файлы из `vers_2/` выкладываются в корень домена.
Node.js на сервере не нужен. Правила nginx и порядок публикации: `../deploy/README.md`.

- `assets/js/config.js` — телефон, адрес, часы, ссылки на WhatsApp / Telegram / MAX, карты, реквизиты, счётчики Метрики.
- `assets/js/menu-data.js` — блюда и цены кухни (сентябрь 2026). Барная карта на сайте не публикуется.
- `assets/che-shashlik-menu.pdf` — меню кухни для скачивания.
- `menu/`, `shashlyk/` — запасная переадресация со старых страниц на `/#menu`.
  Основной HTTP 301 задаётся в `../deploy/nginx-site.conf`.
- `404.html` — страница ошибки, nginx сохраняет HTTP-код 404.
- `assets/js/analytics.js` — согласие, цели Метрики и измерение Core Web Vitals.

## Обновление содержимого

После изменения меню или контактов выполнить в корне репозитория:

```sh
node scripts/build-seo.mjs
node scripts/build-seo.mjs --check
python3 scripts/check-seo.py
```

Генератор обновляет меню, контакты и Schema.org в `index.html` из `config.js`
и `menu-data.js`. Все 68 позиций меню доступны без JavaScript. Генерируемые
блоки отмечены комментариями `menu-nav` / `menu-body`.

Оригиналы фотографий сохранены; для отображения используются WebP-копии.
При добавлении/изменении JPG или PNG выполнить `scripts/optimize-images.mjs`
с установленным Sharp (команда указана в начале скрипта), затем генератор HTML.
Проверка в Chrome: `scripts/check-browser.mjs`; подключение Playwright указано
в начале файла. По умолчанию ожидается локальный nginx на `127.0.0.1:8766`.

## Яндекс Метрика
Счётчики 110450622 (основной) и 105239781 (Яндекс Бизнес), как на прежнем сайте.
Загружаются только после «Принять» в плашке про cookie — на главной,
странице политики и 404. Отзыв согласия останавливает оба счётчика.
Цели — те же идентификаторы, что были: click_phone, click_whatsapp, click_telegram,
click_max, click_route, click_2gis, click_reviews, click_menu_page; в бизнес-счётчик — make-call, make-route.

LCP, CLS и INP передаются в основной счётчик как параметры `web_vitals`
через локальную библиотеку web-vitals 6.2.3, также только после согласия.
Проверка поступления статистики и настройки целей выполняется в кабинете Метрики.

## Яндекс Вебмастер

Поле `yandexVerification` в `config.js` принимает публичный код метатега
из Вебмастера. После заполнения выполнить генератор, опубликовать `index.html`
и подтвердить права в кабинете. Пустое поле не создаёт фиктивный метатег.
При уже подтверждённом DNS/HTML способе поле можно оставить пустым.
