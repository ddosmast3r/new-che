# Фавикон

Красный знак из брендбука на белой плитке со скруглёнными углами (радиус 20 %),
вокруг плитки прозрачно. Белый фон оставлен по просьбе клиента; плитка читается
и на светлой, и на тёмной теме браузера (знак без подложки на тёмной вкладке сливался).

Файлы собраны 7 октября 2026 из `vers_2/assets/brand/ornament.png`, цвет #BF2737:

- `vers_2/assets/brand/favicon-32.png` — 32 px, линии знака утолщены, чтобы не бледнеть во вкладке;
- `vers_2/assets/brand/favicon.png` — 128 px, обычная толщина;
- `vers_2/favicon.ico` — 16 и 32 px с утолщёнными линиями, 48 и 64 px обычные.

На страницах обе PNG подключены с `?v=round-20261007`, чтобы браузеры обновили кеш.
Прежняя версия (квадратный белый фон, промпт для imagegen) — в истории git.
